# Haojie Hu · Personal website

An Astro academic homepage for Haojie Hu (胡浩杰), deployed at <https://imhaojie.github.io>.

Edit the content in `src/data/`. Research internships are in `experience.ts`, papers in `publications.ts`, and project entries in `projects.ts`. Full-size figures and their thumbnails live in `public/assets/`.

With Node.js 22.12 or later, run `npm ci`, then `npm run dev` for local development or `npm run build` for type checking and a production build. Pushing to `main` deploys to GitHub Pages.
